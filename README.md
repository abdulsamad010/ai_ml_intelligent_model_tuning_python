# 🤖 Task 1 — AI-Based Intelligent Classification System

## 🎯 Objective

Train an AI/ML model, process data, predict classes, evaluate performance, accept user input, and visualize results.

## 📚 Dataset

**Breast Cancer Wisconsin Dataset**, loaded directly from Scikit-learn.

| Property | Value |
|---|---:|
| Total samples | 569 |
| Features | 30 |
| Classes | 2 |
| Class labels | Malignant and Benign |
| Training/testing split | 80% / 20% |
| Model | Random Forest Classifier |

## ⚙️ Workflow

```text
Dataset → Inspection → Train/Test Split → Preprocessing
       → Random Forest → Predictions → Evaluation
       → Confusion Matrix → Feature Importance
       → User Selects a Test Sample → Predicted Class
```

## 🧪 Implementation

- Displayed dataset details and sample records.
- Split the data into training and testing sets using stratification.
- Used a Scikit-learn pipeline with missing-value imputation and a Random Forest classifier.
- Calculated accuracy and a classification report.
- Plotted a confusion matrix and top feature importances.
- Added input handling so the user can select a sample from the test set and see its predicted class and confidence.

**Input note:** The user selects a real held-out test sample. This avoids pretending that five feature values represent a complete 30-feature sample. This educational example is not a medical diagnostic tool.

# 📊 Task 2 — ML Model Evaluation and Tuning

## 🎯 Objective

Train multiple classifiers, compare performance, tune a model using cross-validation, and visualize the results.

## 📚 Dataset

**Breast Cancer Wisconsin Dataset**

| Property | Value |
|---|---:|
| Total samples | 569 |
| Features | 30 |
| Classes | Malignant and Benign |
| Training/testing split | 80% / 20% |

## 🤖 Models Compared

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

The notebook compares these models on the same test set, then uses `GridSearchCV` with stratified five-fold cross-validation to tune Logistic Regression.

## ⚙️ Workflow

```text
Dataset → Train/Test Split → Train Three Models
       → Compare Metrics → GridSearchCV Tuning
       → Evaluate Tuned Model → Confusion Matrix
       → ROC Curve → Before/After Comparison
```

## 📏 Evaluation Metrics

| Metric | Meaning |
|---|---|
| Accuracy | Proportion of correct predictions |
| Precision | How many predicted positive cases are positive |
| Recall | How many actual positive cases were found |
| F1 Score | Harmonic mean of precision and recall |
| ROC AUC | Measures classification ranking performance |
| Cross-validation score | Average validation score across folds |
